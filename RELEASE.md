# Подготовка публикации

Плагин использует только публичный Plugin SDK; отдельные патчи ядра не требуются.

Перед отправкой в Community marketplace:

1. Повторить `npm ci`, `npm run typecheck`, `npm test`, `npm run test:ui`, `npm run build` на выбранной версии BB.
2. Проверить реальную передачу macOS → Linux и чтение с удалённого CLI, SHA-256, отказ вне roots, отмену и отключение хоста.
3. Указать публичный repository URL и автора в package.json после выбора репозитория. Не включать локальные настройки shares, host IDs, тестовые файлы или внутреннюю документацию BB-сервис.
4. Опубликовать исходники, LICENSE, README, PLUGIN_OVERVIEW и тег версии. Проверить чистую git-установку через BB: она устанавливает только runtime dependencies, сборка должна работать без dev dependencies.
5. Подготовить marketplace entry по действующему навыку submit-a-plugin. Отправка и принятие в каталог — отдельные шаги; локальная установка не означает публикацию.

Следующие версии: возобновляемые большие передачи, очистка imports по сроку, поиск и ссылки с явным host ID. Для недоверенных локальных директорий нужна платформенная атомарная проверка пути, а не обещание sandbox поверх portable Node fs.
